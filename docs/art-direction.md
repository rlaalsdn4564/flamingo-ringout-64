# 1999 콘솔 대전의 문법, 새 홍학 캐릭터

## 직접 확인한 원작 자료

2026-09-07에 Nintendo의 [N64 공식 소개](https://www.nintendo.co.jp/n01/n64/software/nus_p_nalj/index.html), [Virtual Console 공식 게임 설명](https://www.nintendo.co.jp/wii/vc/vc_dsb/vc_dsb_01.html)을 확인했다. 공식 페이지의 실제 게임 화면을 브라우저로 캡처한 작업용 자료를 직접 관찰했다. 웹 텍스트 도구 자체는 GIF 형식을 표시하지 못했기 때문에, 텍스트 내용만 보고 그래픽을 추측하지 않았다.

관찰한 내용:

- 성채는 회색 벽돌 반복 텍스처와 초록 원뿔 지붕을 사용하고, 멀리 산은 안개 속에 묻힌다. 캐릭터보다 배경 구조가 훨씬 크다.
- 싸움은 횡방향이지만 발판에는 깊이가 있고, 아래쪽 가장자리에 여러 선수의 커다란 피해율이 늘어선다.
- 머리 위의 1P/2P/3P 표시는 작지만 높은 대비를 가진다. 공격 불꽃은 배경 텍스처보다 훨씬 선명하다.
- 다른 무대에서는 목재와 덩굴, 체크 타일, 어두운 배경이 서로 다른 장소를 만든다. 모든 무대를 같은 평평한 배경의 색상 변경으로 처리하지 않는다.

공식 스크린샷은 비교 자료일 뿐이다. 이 저장소에는 스크린샷, Nintendo 캐릭터 모델·음악·텍스처·로고·ROM이 들어 있지 않다. 실제로 재현하지 않은 타이틀 화면이나 모든 원작 기술을 재현했다고 주장하지 않는다.

## 새로 만든 모델과 무대

| 전투원    | 실루엣과 소품                                                  | 동작·플레이 차이                                  |
| --------- | -------------------------------------------------------------- | ------------------------------------------------- |
| 코랄      | 굽은 목, 짧은 스포츠 상의, 붉은 장갑, 트레이너, 두 갈래 머리띠 | 긴 다리를 뻗는 킥, 가장 빠른 대시, 회전 복귀      |
| 마담 수프 | 넓은 몸통, 이중 단추 재킷, 부푼 요리사 모자, 큰 프라이팬       | 무거운 체중, 느린 접근, 큰 팬 스윙                |
| 아주르    | 두꺼운 청록 흉갑, 장식 투구, 긴 창, 타원형 방패, 정강이 보호구 | 긴 공격 거리, 높은 방어 실루엣, 창 찌르기         |
| 루멘      | 가는 몸, 넓은 치마와 망토, 비뚤어진 뾰족모자, 달 장식 지팡이   | 높은 점프, 가벼운 체중, 실제로 이동하는 별 투사체 |

모든 캐릭터는 별도의 절차적 메시 구성이다. 피부색만 바꾸거나 동일한 GLB에 모자만 얹지 않았다. 굽은 목, 눈·갈고리 부리·날개 깃, 엉덩이·무릎·날개·팔꿈치 피벗을 가진다. 원본 메시 소스는 `src/models.js`에 있으며 모델링 앱 없이도 전체 형상을 수정할 수 있다. 이전 모음집의 GLB는 복사하지 않았다.

- **조개왕관 성채:** 따뜻한 석조 성벽, 산호색 기와, 조개 장식, 아치 창, 안개 낀 섬과 물. 원작의 성을 그대로 복사하지 않은 해안 궁전이다.
- **비밀 부들숲:** 큰 굽은 나무와 덩굴, 비대칭 가지 발판, 부들, 토양과 돌 뿌리. 배경의 나무는 안개로 분리한다.
- **달빛 우편선:** 나무 갑판과 금속 선체, 프로펠러, 우편선 객실, 밧줄과 기낭, 달과 밤 구름. 발판 구조부터 앞선 두 무대와 다르다.

## 화면·색·서체 선택

`unslop-ui`의 레퍼런스 기반 방식을 적용했다. 웹 포털의 공통 카드·측면 메뉴·기능 설명을 경기 화면에서 없애고, 4:3 게임 화면과 캐릭터/무대 선택, 하단 피해율·스톡으로 목적을 좁혔다. 타이틀은 주홍·황토색의 각진 입체 글자, 선택 메뉴는 잉크색 바탕과 금색 선택 테두리다. 성채/숲/우편선의 팔레트는 실제 장소의 재질에서 따로 정했다.

한글에는 Galmuri11을 사용한다. 게임 텍스트가 작은 픽셀 형태로 읽히게 하기 위한 선택이다. 로고와 피해율의 굵은 비스듬한 글자는 콘솔 HUD의 낮은 해상도에서 식별되도록 했다. 화면은 800×600으로 렌더링해 확대하며, 안티앨리어싱과 불필요한 블룸을 쓰지 않는다. 브라우저의 reduced-motion 설정에서는 스캔라인과 장식 프로펠러 회전을 끈다.

## 썸네일 생성

캐릭터 초상과 무대 선택 이미지는 실제 플레이 모델을 같은 Three.js 렌더러로 렌더링해서 만든다. 별도의 허위 게임 일러스트가 아니다. 1차 브라우저 QA에서 발견한 `fog.near > fog.far` 오류는 수정했다. 이 오류가 있을 때 초상이 안개색 실루엣으로만 표시되었다.

무대는 먼저 렌더링하고, 전투원·투사체·선수 표시는 깊이 버퍼를 비운 두 번째 3D 패스로 렌더링한다. 이 방식은 캐릭터 내부의 입체 깊이를 유지하면서, 보조 발판 장식이 캐릭터의 긴 목을 가로질러 잘라 보이게 하는 문제를 방지한다. 충돌 평면은 그대로 x/y이며 임의의 화면 좌표로 캐릭터를 옮기지 않는다.
