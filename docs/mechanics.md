# 구현된 경기 규칙

- 플레이어 1명과 CPU 1명의 횡방향 대전이다. 3D 화면이지만 충돌 판정은 x/y 평면에서 계산한다.
- 3스톡, 150초. 장외 경계 x=±22, 아래 y=-10, 위 y=21. 상대를 날려 장외시키면 상대 스톡을 하나 제거한다.
- 스톡을 모두 잃으면 즉시 종료한다. 시간 종료 시 남은 스톡, 낮은 피해율 순서로 판정한다. 완전 동점이면 피해율 200%의 60초 서든데스를 한 번 진행한다. 다시 완전 동점이면 무승부다.
- 자유 연습에서는 CPU가 공격하지 않으며 타이머와 스톡이 소모되지 않는다. 캐릭터의 실제 점프·공격·낙하·복귀 규칙은 유지된다.
- 방향 + 일반 공격은 위/아래/옆으로 나뉜다. 공중 아래 공격에는 아래쪽 넉백을 적용한다. 마녀의 필살기는 별 투사체, 다른 전투원의 옆 필살기는 전진 공격이다.
- 위 + 필살기는 공중 복귀. 접지 전 한 번만 사용할 수 있으며, 두 번의 점프와 별개다.
- 방어는 지상에서만 가능하고 누르는 동안 게이지가 줄어든다. 공격을 막으면 추가로 줄어든다. 타격으로 방어 게이지가 깨지면 2초 스턴이다. 손을 떼면 재생된다.
- 보조 발판에는 아래에서 올라갈 수 있고 아래 방향으로 내려갈 수 있다. 본체 바닥은 통과하지 않는다.
- 가장자리 근처에서 낙하 중이고 피격 경직이 아니면 짧게 매달린다. 점프나 위 방향으로 올라올 수 있다.
- CPU는 접근, 앞뒤 방향 전환, 지형 높이에 따른 중간 발판 선택, 방어, 일반/필살 공격, 장외에서 중앙으로 점프·복귀를 수행한다. 난수는 seed 기반으로 재현 가능하다.
- 난이도는 **입문(기본)** / 보통이다. 입문은 .62~.97초 간격으로 판단하고 피격 중인 상대를 계속 추적하거나 무적 부활 중에 공격하지 않는다. 보통은 .28~.48초 간격으로 판단한다. 플레이어/CPU의 전투원 물리 수치는 동일하다.
- 넉백은 60%까지 피해율 1%당 .045, 그 뒤는 .19로 증가하는 누적 성분을 사용한다. 낮은 피해율에서 바로 강하게 날아가지 않지만, 높은 피해율에서는 분명한 장외 기술이 된다. 가장자리에서 무방비로 연속 공격을 받으면 낮은 피해율에서도 낙하할 수 있다.

## 입력 및 수명

물리는 120Hz 고정 스텝이다. 한 화면 프레임의 지연은 50ms로 제한해 긴 탭 정지 후 대량 프레임을 몰아서 처리하지 않는다. `src/input.js`가 누르고 있는 키와 아직 소비하지 않은 상승 에지를 따로 보관한다. 프레임 사이에 keydown/keyup이 모두 끝난 짧은 점프·공격·필살도 다음 물리 스텝에서 한 번 발동하며, 히트스톱 동안에는 소비하지 않는다. 길게 눌렀다고 무한 점프하지 않는다. 이동/방어는 누르는 동안 유지한다.

Escape/P, 화면 일시정지, 창 포커스 상실, 탭 숨김은 입력을 비우고 경기를 멈춘다. 재경기는 새 match를 만들어 피해율·스톡·시간·경직·투사체·입력을 초기화한다. 화면 전환 때 접근성 안내 문구도 초기화한다. 터치 조작은 pointer capture와 pointerup/pointercancel/lostpointercapture 해제를 사용한다.

소리는 기본 꺼짐이다. 사용자가 켰을 때만 브라우저 오디오 컨텍스트를 만들고 짧은 합성 효과음을 재생한다. 음악이나 원작 효과음 파일은 없다. 페이지를 닫으면 RAF, 오디오, WebGL 리소스를 해제한다.

## 범위와 한계

이 게임은 Nintendo 64 ROM 재현이나 원작의 완전한 복제물이 아니다. 온라인 대전, 4인전, 게임패드, 아이템, 잡기/던지기, 캠페인은 구현하지 않았다. 캐릭터별 수치는 독자적으로 튜닝했으며 경쟁 대전용 프레임 데이터와 밸런스를 보장하지 않는다. 터치 버튼은 제공하지만 실제 휴대전화 기기에서의 장시간 플레이 검증과 브라우저의 실제 키 입력 검증은 별도 QA 기록을 확인해야 한다.
