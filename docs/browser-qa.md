# 실제 브라우저 검수

2026-09-07 · macOS Codex 내장 Chromium · 1280×720 · 로컬 Vite 4209.

- 타이틀 → 자유 연습 → 루멘/부들숲 선택 → READY TO FIGHT 진입.
- 실제 선택 화면에서 전투원 네 명의 서로 다른 모델과 성채/숲/우편선 세 무대의 컬러 미리보기를 확인했다. 최초 안개 범위 오류를 고친 결과다.
- 짧은 X 입력으로 별 투사체가 발사됐으며 CPU 피해율이 0%에서 9%로 증가했다. Space 입력으로 실제 공중 상승과 보조 발판 착지를 확인했다. 상태 주입 없이 키보드로 조작했다.
- 전투원 분리 렌더 패스 수정 뒤 몸과 목이 발판에 잘려 사라지지 않고 표시되는지 확인했다.
- Escape 일시정지, 계속하기, 재경기와 선택 복귀를 확인했다. 재경기 후 이전 결과 안내가 남지 않는다.
- 검수 시 브라우저 warning/error 로그 0건. 상하 HUD와 조작 안내가 뷰포트 안에 보인다.
- `preview.jpg`는 루멘의 실제 부들숲 플레이와 CPU 9% 적중 뒤 캡처이며 합성 목업이나 CPU 캡처가 아니다.
- 수명주기 수정 후에도 새 대전에서 루멘·부들숲 선택 → 3스톡/150초 대전 → P 정지 → 계속하기의 실제 전투 재개를 재확인했다. 이것을 실제 bfcache 복원 검사로 간주하지 않는다.

최신 40개 자동 테스트, 48 CPU 대전 시뮬레이션은 별도 [검증 기록](verification.md)에 있다. 자동 입력 대전은 사람이 끝까지 플레이했다는 뜻이 아니다. 추가된 P/Escape·페이지 수명주기 회귀는 CPU 검증이며 **실제 브라우저의 bfcache 복원은 미검증**이다. 모바일 실기기, 긴 키 누름을 통한 전 대전 완주, 오디오 출력 및 게임패드는 검수하지 않았다. 문서 갱신 시 확인한 548.10KB 단일 JS chunk의 크기 경고는 남아 있다.
