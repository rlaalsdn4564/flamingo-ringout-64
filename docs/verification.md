## 브라우저와 구분

부모 작업에서 실제 브라우저로 수행한 1차 점검은 타이틀/선택/성채·부들숲 연습/재경기/일시정지/콘솔을 포함했다. 그 점검에서 다음 실제 문제가 발견되어 수정했다.

1. 썸네일 안개 범위 역전 → 수정 후 실제 브라우저에서 네 캐릭터와 세 무대의 색·텍스처 복원 확인을 전달받았다.
2. 낮은 피해율부터 큰 넉백 → 입문/보통 선택과 누적 피해 곡선 수정, 자동 회귀 검사 추가.
3. 재경기 접근성 안내에 이전 승자 잔존 → 화면 전환 때 초기화.
4. 보조 발판이 전투원 목을 가림 → 별도 전투원 3D 렌더 패스.
5. 짧은 Space/Z/X가 프레임 사이에서 유실 → 입력 에지 보존 및 해제/취소/일시정지 초기화 테스트.

4번과 5번의 최종 수정 후 실제 브라우저 재검증은 부모 작업의 별도 `browser-qa.md`에 기록해야 한다. 이 문서는 하지 않은 입력/기기 검증을 통과했다고 주장하지 않는다. 물리 엔진 테스트는 실제 WebGL 렌더링·터치 하드웨어·성능 측정·장시간 사람 플레이를 대신하지 않는다.
